# Revit и MCP4–MCP6

## Общая идея

RAG ищет информацию в проиндексированных документах. MCP используется для обращения к внешним инструментам и получения актуальных структурированных данных.

## MCP4 — извлечение данных Revit

MCP4 принимает отдельный `.rfa`, `.rvt` или папку. При обработке папки он рекурсивно ищет `.rfa` и пропускает папки, похожие на каталоги паспортов/PDF.

Для свежего извлечения Revit 2024 должен быть запущен с add-in MCP4. Внешний MCP4 передаёт запрос через named pipe `BIMS_FAMILY_BRIDGE_ENGINEERING_V2`, а add-in выполняет Revit API через `ExternalEvent`.

Исходный файл копируется во временную рабочую копию; документ открывается программно через Revit API и после чтения закрывается без сохранения.

Для каждого FamilyType add-in переключает `FamilyManager.CurrentType`, вызывает `Document.Regenerate()` и после этого читает значения параметров, коннекторы и состояние геометрии конкретного типа.

MCP4 извлекает, где это доступно: параметры и их идентичность, формулы, типы, геометрию, коннекторы, материалы, вложенные семейства, опорные плоскости, видимость, lookup tables и визуальные данные. Числовые инженерные значения нормализуются из внутренних единиц Revit через `UnitUtils`/спецификацию параметра.

Неполные или недоступные блоки помечаются как `partial` или `missing`.

## MCP5 — сравнение

MCP5 работает с JSON MCP4 и не требует открытого Revit. Он сравнивает структурированные признаки семейств: параметры, типы, формулы, геометрию, коннекторы и другие извлечённые компоненты.

## MCP6 — рекомендации

MCP6 также работает с подготовленными данными, а не напрямую с Revit API.

```text
mcp6-call recommend-family-unification V001
```

Формирует рекомендации по унификации библиотеки.

```text
mcp6-call recommend-family-from-passport V001
```

Использует данные MCP4/MCP5 вместе с выбранным PDF-паспортом оборудования и формирует рекомендации по семейству-основе и изменениям.

## Два Revit bridge

В BimSAgent существуют два разных локальных bridge:

- `BIMS_REVIT_BRIDGE` — Revit-интеграция основного BimSAgent/MCP1-сценариев;
- `BIMS_FAMILY_BRIDGE_ENGINEERING_V2` — отдельный bridge MCP4 для инженерного извлечения семейства.

Они не заменяют друг друга.
