# Архитектура BimSAgent

## Назначение

BimSAgent — консольный AI-ассистент на C#/.NET для задач Autodesk Revit/BIM. В одном приложении объединены обычный диалог с LLM, RAG, память, профили, задачи, MCP-инструменты, Revit-интеграция и локальный HTTP-сервис.

## Режимы запуска

`Program.cs` разделяет несколько режимов:

- `dotnet run` — интерактивный BimSAgent в терминале;
- `dotnet run -- serve` — локальный HTTP-сервис;
- `dotnet run -- rag ...` — отдельные RAG-команды;
- `dotnet run -- family pipeline ...` — конвейер MCP4 → MCP5 → MCP6.

При обычном запуске программа показывает активный LLM и текущую стратегию контекста.

## LLM

BimSAgent поддерживает OpenAI и локальный Ollama. Обычный текст пользователя обрабатывается активным LLM-провайдером, если запрос не перехвачен отдельной командой или локальной логикой.

## Контекст и память

В BimSAgent существуют отдельные механизмы контекста: история диалога, факты, short-term/working/long-term memory, пользовательские профили, задачи и стратегии контекста.

Стратегии контекста включают `sliding-window`, `sticky-facts` и `branching`.

RAG является отдельной подсистемой и хранит собственный индекс документов.

## RAG

Код RAG расположен в папке `Rag/`. Текущий процесс включает извлечение текста, разбиение на чанки, embeddings, сохранение индекса, retrieval/reranking, сбор контекста и генерацию ответа на основе найденных фрагментов.

На момент этой версии команда `rag index` принимает один документ формата `.docx` или `.pdf`. Поддержки `.md` и автоматического индексирования всей папки `docs` в текущем коде ещё нет.

## MCP

`McpCommands.cs` содержит подключение MCP1–MCP6 и вызов их инструментов. MCP даёт BimSAgent доступ к внешним данным и операциям; это отдельный механизм от RAG.

MCP4–MCP6 образуют конвейер работы с библиотекой Revit-семейств:

`MCP4 → структурированные данные → MCP5 → сравнение → MCP6 → рекомендации`.

## Revit-интеграция

В проекте есть Revit Add-in, выполняющий Revit API внутри процесса Revit через `ExternalEvent` и локальный named-pipe bridge `BIMS_REVIT_BRIDGE`.

Для MCP4 используется отдельный Revit Add-in и отдельный named pipe `BIMS_FAMILY_BRIDGE_ENGINEERING_V2`. MCP5 и MCP6 работают с уже подготовленными данными и не вызывают Revit API напрямую.
